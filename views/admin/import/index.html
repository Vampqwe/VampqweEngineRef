Как это работает:

  1. Загрузите HTML-файл страницы
  2. Система автоматически извлечёт: заголовок, описание, контент (между <!-- ОСНОВНОЙ КОНТЕНТ --> и <!-- CTA -->), картинки и стили
  3. Картинки будут скачаны и сохранены локально
  4. Стили из тегов <style> будут перенесены в промежуточный файл /storage/neutral-style.css (дубли правил заменяются)
  5. Inline-стили и все классы HTML сохраняются как есть — контент переносится в БД без изменений
  6. JS-скрипты: путь по умолчанию ["/assets/js/main.js"], canonical строится из APP_BASE_URL + slug
  7. Контент пройдёт санитизацию (удаление опасных тегов)
  8. Вы увидите предпросмотр и подтвердите импорт
Допустимые форматы: .html, .htm
